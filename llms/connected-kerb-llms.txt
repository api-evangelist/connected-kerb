# Connected Kerb

> Connected Kerb is a UK electric-vehicle charging company that designs, installs, owns and operates public on-street and destination charge points, with a particular focus on residential drivers who have no off-street parking. Founded in 2017 and headquartered in London, it delivers long-term charging concessions for local authorities, workplaces, retail destinations, car parks and residential developers, and by mid-2026 operated roughly 7,800 public chargers across about 1,780 UK locations.

This file was generated by API Evangelist from a public probe of Connected Kerb's own hosts on 2026-08-04. Connected Kerb does not publish an llms.txt, a developer portal, or a machine-readable API description of its own.

## APIs

- [Connected Kerb OCPI (CPO) Interface](https://cp.connectedkerb.com/ocpi/versions): Live Open Charge Point Interface endpoint. Versions 2.1.1, 2.2 and 2.2.1 all answer; token-gated per the OCPI credentials module. Used for e-mobility roaming and for the machine-readable charge point data named by the UK Public Charge Point Regulations 2023.
- [Connected Kerb Charge Point Platform API](https://cp.connectedkerb.com/public-api/): Server-to-server API for charge points, EVSEs, locations, sessions, users, tariffs, partners and roaming. Bearer API token, issued through the operator back office. The contract governing it is published by the platform vendor, not by Connected Kerb.

## Access

- Both API surfaces are gated. There is no self-service sign-up for API credentials.
- OCPI access requires a bilateral credentials exchange (commercial roaming agreement).
- Platform API access requires an API access token created in the operator back office.
- The OAuth 2.0 client-credentials grant described by the platform contract is not enabled on Connected Kerb's tenant.
